# deep-survival-metabric

Análisis de supervivencia en cáncer de mama con el dataset METABRIC: comparación de DeepSurv y DeepHit frente al modelo de Cox.

## Instalación
```bash
pip install -e .
```

## Datos
Descarga METABRIC desde [enlace] y guárdalo en `data/` (esta carpeta no se sube al repo).

## Estructura
- `docs/`: documentación del proyecto (charter, datos, modelado, aceptación)
- `scripts/`: notebooks y scripts por etapa
- `src/deep_survival/`: código reutilizable del paquete
